## Technical Implementation

### Vite Configuration

```typescript
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";

export default defineConfig({
  plugins: [react()],
  build: {
    outDir: "../public",
    emptyOutDir: true,
  },
});
```

### Tailwind v4 CSS

`ui/src/index.css`:

```css
@import "tailwindcss";
```

The `@theme` block will be populated by shadcn init. Use the CSS-first config approach — no `tailwind.config.ts`.

### shadcn/ui Initialization

```bash
cd ui && npx shadcn@latest init --preset nova --template vite
```

This sets up the component infrastructure, `cn()` utility, and CSS variables. Do not add any specific shadcn components yet — those come in ISSUE-20 through ISSUE-22.

### npm Script Update

```json
"build:ui": "cd ui && npm run build"
```

Or if using npm workspaces, set up the `ui` package as a workspace and use `npm run build -w ui`.

## Manual Tests

1. Run `npm run build` — completes, `public/index.html` exists and contains React app mount point
2. Run `npm start` — serves the React app at `http://localhost:8787`, shows "Video Processing Pipeline" heading
3. Run `npm run check` — all checks pass including TypeScript for both `src/` and `ui/`

## Other Notes

The `ui/` directory is a separate npm package with its own `package.json`. Dependencies are installed separately (`cd ui && npm install`). The root `package.json` orchestrates via scripts, not npm workspaces (unless the implementer chooses to set up workspaces — either approach is acceptable).
